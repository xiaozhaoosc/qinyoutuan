## 功能增强

### 完整自动化测试流水线
- 新增 `scripts/test-full.sh`：10 步完整回归，与本仓 `.github/workflows/ci.yml` 对齐，可作为本机/服务器跑的本地 CI
  1. `go build ./...`
  2. `go vet ./...`
  3. `go test -race -count=1 ./...`（含数据竞争检测）
  4. 测试用例清单收集（`go test -list` 按包，产物落盘）
  5. bash 语法检查（`install.sh` / `install-singbox.sh` / 本脚本）
  6. Argo 专项套件（复用 `test-argo.sh`）
  7. 前端 node:test 单测
  8. 前端 vue-tsc 类型检查
  9. 前端 vite build（产出 dist 供 go embed）
  10. 启动冒烟（临时库 + `/api/health` + 引导日志）
- 每次运行自动生成三份可归档产物到 `docs/test-report/`：
  - `test-cases.md`（测试用例清单）
  - `result-<时间戳>.md`（当次结果 + 每步耗时 + 失败报文）
  - `latest.md`（软入口）
- 使用文档：`docs/test-report/README.md`
- 支持开关：`--no-frontend` / `--no-smoke` / `--keep-logs`；`GO=`、`QZ_PORT=`、`CGO_ENABLED=` 环境变量

## Bug 修复

### 监控详情图长范围静默截断
- **问题**：`ListMetrics` 硬上限 5000 行，在默认 30s 采样下，7d≈2 万行 / 30d≈8.6 万行，长范围监控图被静默裁剪成最近约 1.7 天，但界面仍宣称显示 7d/30d。
- **修复**：窗口行数 ≤ 上限走精确路径；超过则按实际数据跨度分桶（AVG/MAX 聚合）覆盖完整时间窗。前端无需改动。
- 新增 `TestListMetricsDownsamplesLongWindow` / `TestListMetricsExactUnderCap`。

## 性能 / 稳定性优化

### 流量采样默认周期缩短
- 默认流量采样周期由 10 分钟调至 5 分钟，缩小"换 IP 触发 sing-box 重启"导致的瞬态丢数窗口减半。
- `reconcile` 默认 60min > 5min，不受 stats 下限钳制，不引入额外全量 SSH 下发副作用（已在 `Controller` 钳制逻辑核实）。

## 已知残余风险（暂缓）
- sbstats 采用 `reset=true` 从 sing-box 拉增量，节点/sing-box 重启的瞬间窗口内流量可能丢失（协议固有、无重试可回填）。根治需改累积差值法（读累积值 + 面板持久化基线），改动中等、回归风险略高，暂缓。

4. 验证监控详情图在 7d/30d 范围显示完整
